About Hidenly

Hidenly detects and reveals hidden messages encoded using invisible Unicode characters.

How it works:

  • 🔍 Automatically scans web pages for hidden content
  • 🔔 Shows badge notification when content is found
  • 🔓 Decode hidden messages directly in the sidebar
  • ⚡ Uses WebAssembly for fast processing

Features:

  • Real-time page monitoring
  • Support for text and image decoding
  • Tab-based interface for easy navigation
  • Privacy-focused: all processing happens locally
