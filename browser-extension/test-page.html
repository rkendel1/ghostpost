What to Expect:

  • Extension badge should show a count (e.g., "2" for two hidden messages)
  • Sidebar Detection tab should list the elements containing hidden content
  • Clicking "Decode" on a message should reveal the hidden text
  • The decoder tab should allow manual decoding of any copied text

Troubleshooting

If the extension doesn't detect the hidden content:

  • Make sure the extension is properly installed and enabled
  • Check the browser console for any errors (F12)
  • Try clicking "Rescan Page" in the extension sidebar
  • Refresh the page
